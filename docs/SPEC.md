# 仕様書（BALLSTORM -BBOD- Ver.1.1）

Ver.1.0 は Ver.0.1.6 時点のゲーム内容（バランス・演出・操作）をそのまま公開版にしたもの。変更は開発用キーの無効化とタイトル表記のみ（その後スマホ操作・OGP を追加）。
Ver.1.1 でスコア到達イベント（200万 / 500万 / 1,000万点）とストック超過ボーナスを追加。難易度・速度・出現率・操作・時間倍率は変更なし。

数値はすべて `js/config.js` の定数。ここでは定数名を併記する。

## 1. 基本方針
- HTML5 Canvas + 素の JavaScript。外部ライブラリなし。
- 見た目より「操作感・ボール物理・大量破壊の爽快感」を優先。
- PC（マウス）向け。Pointer Events を使い、将来のスマホ対応を考慮。
- 論理解像度 600×820（縦長）。ウィンドウに合わせて拡大縮小し、devicePixelRatio に対応。

## 2. 決定事項（依頼仕様）
### 基本ルール
- アルカノイド型。パドルは画面下部でマウスに追従。
- ボールが全て失われたらゲームオーバー。リスタート可能。
- 一定時間ごとに上から新しい列が補充され、既存ブロックは1段下へ押し下げられる（`ROW_INTERVAL_*`）。
- ボール速度は 60 秒ごとに 10% 上昇（複利、`SPEED_UP_INTERVAL` / `SPEED_UP_RATE`）。速度上限なし。

### ブロック
| 種類 | 見た目 | 効果 |
|---|---|---|
| 通常 | 行ごとに色が変わる | 破壊・スコア加算 |
| ボール増殖 | 緑＋「＋」 | 破壊時、衝突地点から新ボール1個。元のボールは通常反射 |
| ボール捕獲 | 格子の中にボール | 破壊すると中のボール1個を解放（プレイヤーのボール扱い） |
| ボール吸収 | 紫に光る渦 | 命中したボールは消滅 |
| 装甲（Ver.0.1.6） | 鋼板＋リベット、削れるとひび | 耐久5。破壊で基本1,000点 |

### 分裂アイテム
- ストック上限 3。Space で発動、ストック全消費。
- 1個:4倍 / 2個:8倍 / 3個:12倍（`SPLIT_COUNTS`）。分裂後は通常のボール。
- ~~ボール数の上限なし~~ → Ver.0.1.6 で変更：**ボールが10個以下の時だけ使用可能**、ボール全体の上限は119個（下記「難易度・得点バランス」）。

### 難易度・得点バランス（Ver.0.1.6 で追加）
目的：ボールを増やすほど有利になりすぎるのを抑え、時間をかけて高得点を狙う遊びにする。
- **分裂の使用条件**：ボールが `SPLIT_MAX_BALLS`（10）個以下の時だけ Space で発動。11個以上の時はストックを消費せず「SPLIT: 10球以下で使用可」と表示。ストックの取得は通常どおり。HUD のストック表示は使えない間は暗くなり、ラベルが「SPLIT ≤10球」になる。
- **ボール生成上限**：`BALL_LIMIT`（119）。分裂・増殖ブロック・捕獲ブロック・MILLIONAIRE の追加ボールすべてに適用。上限に近い時は入る数だけ追加し、既存のボールは消さない。ボールが減れば再び増やせる。
  - 分裂で上限に収まらない時は、追加できる数を各ボールに均等に割り振り（余りは先頭から1個ずつ）、各ボールは自分の個数で扇状に広がる。例：10個×12倍 → 119個。
  - 上限時に増殖・捕獲ブロックを壊した場合、ブロックは壊れて点は入るが、ボールは出ない。
  - MILLIONAIRE は空きの数だけ（最大32個）を均等配置。
  - HUD のボール数の横に、上限到達中は「MAX」を表示。
- **P（貫通）と G（グラビティ）の出現比率**：アイテムブロックを生成した時点のボール数で、P と G の重みに倍率を掛ける（`ITEM_PG_RATE_BANDS`）。アイテム全体の確率（通常ブロックの7%）は変えず、減った分は S と R の比率が上がる。発動中の効果は弱めない。

  | ボール数 | P・G の倍率 | 比率 S:R:P:G（実測） |
  |---|---|---|
  | 1〜9 | 100% | 40:20:20:20 |
  | 10〜29 | 50% | 50:25:12.5:12.5 |
  | 30〜59 | 25% | 57:29:7:7 |
  | 60以上 | 10% | 62.5:31:3:3 |
- **装甲ブロック**：
  - 耐久 `ARMOR_HP`（5）。ボールが1回当たるごとに1減り、0で破壊。破壊点 `SCORE_ARMOR`（1,000）×時間倍率。
  - 通常のボールは反射する。貫通ボールは反射せずに通り抜け、**1回の通過で1ダメージ**（重なっている間は毎フレーム削らない。ボールごとに重なっている装甲ブロックを覚え、重なり始めた時だけ減らす）。
  - 見た目：灰色の鋼板に白い縁と四隅のリベット。ダメージごとに暗くなり、ひびが1本ずつ増える（4段階）。削れた時は小さな金属音と火花、破壊時は破砕音・粒子・小さな画面揺れ・得点表示。
  - 出現率：**列を生成した時点のボール数**で決まる（`ARMOR_RATE_BANDS`）。空でないマスのうちこの割合が装甲になる。既に置かれたブロックは後から装甲にならない。

    | ボール数 | 1〜9 | 10〜29 | 30〜49 | 50〜79 | 80以上 |
    |---|---|---|---|---|---|
    | 出現率 | 3% | 5% | 10% | 20% | 30% |
- **時間倍率**：`SCORE_MULT_INTERVAL`（60）秒ごとに ×1.1 の複利（1.1, 1.21, 1.331…）、上限 `SCORE_MULT_MAX`（10倍。24分で9.85倍、25分で上限に到達）。通常ブロックと装甲ブロックの破壊点に掛ける（端数は四捨五入）。経過時間に連動するので一時停止中は進まず、リスタートで1倍に戻る。HUD の「SCORE」ラベルの横に小さく「×1.21」のように表示（1倍の間は暗い色、以降は金色）。

### アイテムの取得方式（Ver.0.1.1 で変更）
- 一部のブロックがアイテムを持つ。**破壊した瞬間に自動取得**する（落下アイテム・パドルでの取得は廃止）。
- 分裂アイテム（S）：即座にストックへ追加（上限3、上限時は増えない）。
- 回転パドル（R）・貫通ボール（P）：即座に発動。効果中に同じアイテムを再取得すると残り時間を初期値に戻す（加算はしない）。
- 取得時：効果音＋取得地点に色付きの波紋・粒子・アイテム名の文字表示。
- 貫通ボールで壊した場合も取得できる。

### 回転パドル
- 通常パドルと同じ長方形の補助パドル3枚が、通常パドル中心で扇風機の羽のように回転。
- 専用アイテム（R）で `ROTOR_DURATION` 秒発動。回転速度 `ROTOR_ANGULAR_SPEED`。
- 反射は「羽の面の法線」と「接触点の羽の速度（回転速度＋パドル移動速度）」から計算する相対速度反射（ランダム要素なし）。

### 貫通ボール
- 専用アイテム（P）で `PIERCE_DURATION` 秒、全ボールが貫通状態（オレンジ色＋光）。
- ブロックを反射せず連続破壊。壁・パドルでは通常反射。特殊ブロックの効果も発動。

### グラビティ・リバウンド（Ver.0.1.4 で追加）
パドルの周囲に力場を作り、近づいたボールを引き寄せてパドル直前で強く弾き返す。パドルを動かしてボールを迎えに行くことで効果を発揮する（自動回収ではない）。
- 取得：「G」の印のブロックを壊した瞬間に自動取得。`GRAVITY_DURATION`（15秒）有効。効果中の再取得で残り時間を初期値に戻す。
- 出現率：アイテム全体の確率（通常ブロックの7%）は据え置き、種類の比率を 分裂50:回転25:貫通25 → **分裂40:回転20:貫通20:グラビティ20** に配分し直した。
- 吸引：
  - 中心はパドル上面の中央。パドルと一緒に動く。
  - 範囲は画面高さの20%（164px、`GRAVITY_RANGE_RATIO`）。範囲外のボールは一切影響を受けない。
  - 引力 = `GRAVITY_ACCEL`(7000) ×（1 − 距離/範囲）^`GRAVITY_FALLOFF`(0.7) ×（基準速度/初速）² px/秒²。近いほど強く、範囲の端で0。速度の2乗で強めるので、時間経過で速くなっても曲がり方は同じ。
  - ボールの速さは変えず、進行方向だけを曲げる。
  - 対象は「下向きに進んでいて、パドル上面より上にいる」ボールだけ。引力は常に下向きの成分を持つので、力場の中で周回したり上へ戻されたりしない。
  - 目安：真上から落ちるボールは、パドル中心から約110px（パドル端の外側約60px）まで回収できる。パドルをボールへ寄せれば140px離れていても回収できる。
- 急反発：
  - ボールの下端がパドル上面から26px以内（`GRAVITY_REBOUND_DEPTH`）、かつパドル幅＋左右14px（`GRAVITY_REBOUND_MARGIN_X`）の範囲に入ると、パドルに触れる前に弾き返す。
  - 方向は基本的に上向き。当たった位置で角度が付き（通常パドルの最大角の0.75倍）、ボールの横の勢い（30%）とパドルの移動速度（25%）を加える。最低でも水平から35°上向き。
  - 速度は基準速度の1.3倍（`GRAVITY_REBOUND_SPEED`）。その後は既存の仕組みで基準速度へ徐々に戻る。
  - 同じボールは0.3秒間（`GRAVITY_REBOUND_COOLDOWN`）再反発しない。
  - グラビティ中に、ボールがパドル側面から本体の高さへ入り込んだ場合は、上面へ持ち上げて急反発させる（パドルの下へ抜けるのを防ぐ）。
- 組み合わせ：貫通・回転パドル・分裂と同時に使える。分裂で増えたボールにもすべて効く。回転パドルの羽との衝突は従来どおりで、急反発は羽より先に判定する（0.3秒のクールダウンで交互の連続反発を防ぐ）。
- 演出：パドル上にピンクの半円の力場と内側へ縮む輪、パドル直前の反発領域の帯、パドルのピンクの縁取り。吸引中のボールにピンクの軌跡（最大60個まで）。急反発時はパドルが光り、波紋と粒子（1フレーム最大4回まで）と効果音。終了3秒前から点滅。
- 開発用キー：4 で即時取得。

### 特別イベント「MILLIONAIRE」（Ver.0.1.5 で追加）
100万点に初めて到達したご褒美の演出。ゲームは止めずに並行して進む。
- 発動：1プレイ中にスコアが初めて `MILLIONAIRE_SCORE`（1,000,000）以上になった瞬間に1回だけ。判定は毎フレームのボール処理の後に行うので、一度に大きく超えた場合も発動する。減点で100万点を下回って再び超えても再発動しない。リスタートでフラグを戻す。
- 花火：画面下から光の玉が火花を引きながら約0.9秒（`MILLIONAIRE_RISE_TIME`）で上昇し、画面上半分で炸裂。ブロックより奥のレイヤーに描く。炸裂点は画面高さの32%を目安に、ブロックの塊と重なる時はその少し下へずらす（ただし画面の上半分まで）。
- 炸裂：金色中心の光の粒160個（`MILLIONAIRE_SPARKS`）が3重の輪で広がり、空気抵抗で減速しながら約1.1〜1.6秒で消える（同時表示は最大400個、寿命が来たら配列から削除）。画面に薄い金色のフラッシュ。「MILLIONAIRE!」と「1,000,000 POINTS — +32 BALLS」を画面中央に約2秒表示（最後の0.5秒でフェードアウト）。演出全体は約2.9秒。
- ボール追加：炸裂地点から `MILLIONAIRE_BALLS`（32個）を放射状に発射。通常のボールとして扱い、既存のボールはそのまま。初速はその時点の基準速度 ×`MILLIONAIRE_BALL_SPEED`（1.0）。真横付近（水平から14°以内）は既存の角度補正があるため、そこを除いた上下それぞれの範囲に均等配置（16個ずつ、間隔約9.4°）。
- 炸裂点がブロックと重なっていても、既存の衝突処理で押し出されるのでボールは止まらない。
- 花火の上昇中（約0.9秒）は、ボールが0個になってもゲームオーバーにしない（直後に32個届くため）。
- 効果音：打ち上げ（上昇する笛の音＋かすかなノイズ）と炸裂（ノイズの破裂音＋低い響き）。効果音全体の音量 `SFX_VOLUME` の範囲内で控えめ。BGMは止めない。効果音は最初のクリック/キー操作で音声を有効化した後に鳴る（ブラウザの自動再生制限）。

### スコア到達イベント（Ver.1.1 で追加）
100万点の MILLIONAIRE（上記、+32球）はそのまま。200万点以上の3段階は **視覚・音響演出のみ**（ボール・ブロック・得点・速度・時間倍率・難易度は一切変えない。ゲームも止めない）。

| 点数 | 称号 | 演出 |
|---|---|---|
| 2,000,000 | DOUBLE MILLIONAIRE! | 青白い花火1発、青白い衝撃波2重、青白いフラッシュ、4音の分散和音 |
| 5,000,000 | MEGA MILLIONAIRE! | 金色の花火3発（左右に間隔0.28秒）、金の衝撃波、金のフラッシュ、2層の分散和音 |
| 10,000,000 | OVERDRIVE LEGEND! | 虹色7色の花火5発、多色の衝撃波3重、白いフラッシュ、虹色に流れる称号、長い分散和音＋最後の和音 |

- 設定：`SCORE_EVENTS`（点数・文言・色・花火数・粒の数・衝撃波の数・表示時間・効果音）と `SCORE_EVENT_*`（粒の上限・上昇時間・間隔・称号の位置と大きさ・連続時の間）。
- 判定：毎フレーム、ボール処理（＝ブロック破壊・アイテム取得・ストック超過ボーナスなど、すべての得点加算）の後に、MILLIONAIRE と同じ場所で「スコアが閾値以上で未発動」を調べる（`checkScoreEvents`）。得点の加算箇所に手を入れていないので判定漏れがない。一度に複数の閾値を超えた場合も、すべて発動済みにして演出を予約する。
- 1プレイ1回ずつ。減点で下回って再び超えても再発動しない。リスタートで発動履歴・花火・称号をすべて消す。
- 重なり対策：同時に発動した場合は、前の称号（MILLIONAIRE のメッセージを含む）が消えて0.3秒後に次を表示する（例：一気に1,050万点 → MILLIONAIRE → 3.6秒後 DOUBLE → 5.9秒後 MEGA → 8.6秒後 LEGEND）。称号は常に1つだけ。
- 表示：花火の粒と衝撃波はブロックより奥のレイヤー（MILLIONAIRE と共通の描画・粒の更新処理を再利用）。称号は画面高さの42%（ボールとパドルが多い下側を避ける）に2.0〜3.0秒、半透明・最後の0.5秒でフェードアウト。文字は38px を基準に、画面幅（左右20px の余白）に収まらない時は自動で縮める。Canvas ごと拡大縮小するのでスマホでも切れない。
- 負荷：花火の粒は MILLIONAIRE の粒と合わせて最大700個（`SCORE_EVENT_SPARK_MAX`）、寿命1.0〜1.5秒で配列から削除。衝撃波は最大3重×0.9秒。

### ストック超過ボーナス（Ver.1.1 で追加）
- 分裂ストックの上限は3のまま。0〜2個の時に S を取ると従来どおり1個増える。
- 3個の時に S を取ると、ストックは3のまま **5,000点**（`STOCK_OVERFLOW_BONUS`）。時間倍率は掛けない（常に5,000点）。表示「STOCK MAX! +5,000」（金色）、効果音 `stockBonus`（短い2音）。
- アイテム取得の基本点（`SCORE_ITEM` 50点）は従来どおり別に入る（S を取った時の合計は 50 + 5,000 = 5,050点）。
- ボーナスで100万・200万・500万・1,000万点を超えた場合も、上記の共通判定で各イベントが発動する。
- 分裂の使用条件（ボール10個以下）は変更なし。PC（Space）・スマホ（SPLIT ボタン）共通の処理。

### 開発用キーの無効化（Ver.0.1.5 で追加）
- `DEV_KEYS_ENABLED` を false にすると、開発用キー（D / 1〜4 / B / Ctrl+Shift+F8・F9）がすべて無効になり、デバッグ表示も出なくなる。**Ver.1.0（公開版）では false**。開発時は true に戻して使う。
- タイトル（ブラウザのタブ表記）は「BALLSTORM -BBOD- | 増殖・分裂ボールで壊しまくるエンドレス・ブロック崩し」（Ver.1.0、OGP対応時に説明を追加）。ゲーム画面内にはタイトル表示なし。

### スマートフォン操作（Ver.1.0 で追加）
ゲームルール・得点・アイテム・演出・ボール速度・119球制限は変更なし。入力と画面配置だけの対応。
- **タッチ用表示の有効化**：タッチ主体の端末（`(hover: none) and (pointer: coarse)`）では最初から、タッチ対応PCでは最初にタッチした時に `body.touch-ui` を付ける。一度付けたらそのページを開いている間は維持（PCでマウスだけ使う場合は従来の表示のまま）。
- **パドル**：ゲーム画面、または下の操作バーの空き部分に触れた指の位置へパドルを合わせる（画面上の位置を Canvas の表示サイズからゲーム座標 600×820 に換算）。最初に触れた指だけがパドルを動かす。指を離してもパドルは最後の位置に留まる。ポインターロックはタッチでは要求しない。
- **タップ**：ゲーム画面で「12px 以内の動き・400ms 以内」で離すとタップ。発射待ちなら発射、一時停止中なら再開、ゲームオーバーならリスタート。プレイ中のタップは何もしない。なぞる操作は発射にならない。
- **操作バー**（ゲーム画面の下、幅はゲーム画面に揃える、高さ76px）：
  - 左：一時停止ボタン（II ⇔ ▶、60×56px）、BGM ボタン（♪ ON / OFF）
  - 右：分裂ボタン「SPLIT ×ストック数」（150×60px）。Space と同じ `activateSplit()` を呼ぶので、ストック数・倍率・「ボール10個以下」の条件はPCと同じ。プレイ中でストック1以上かつボール10個以下の時だけ明るく、それ以外は暗い表示で押しても何も起きない。
  - ボタンは押した瞬間に1回だけ実行（長押しで連続しない）。ボタンに触れた指はパドル移動・タップ判定に使わない（発射・リスタートとの二重処理なし）。
  - HUD の分裂ストック部分のタップで分裂する従来の操作も残している。
- **誤操作防止**：タッチ時は body・ゲーム画面・操作バーで `touch-action: none`、`touchstart` の既定動作を止める（スクロール・ダブルタップ拡大・長押しメニュー）。iOS のピンチ拡大（`gesturestart`）とテキスト選択も無効。viewport は拡大不可。
- **画面配置**：縦持ち基準。ゲーム画面は縦横比 600:820 を保ったまま、セーフエリア（`env(safe-area-inset-*)`、viewport に `viewport-fit=cover`）と操作バーの高さを除いた範囲に収める。画面の回転時にも再計算。⚙（設定）ボタンはマウス用の設定なのでタッチ表示では隠す（キーボードがあれば O で開ける）。
- **案内文**：タッチ表示の時は「タップで発射」「タップ または ▶ で再開」「タップでリスタート」とタッチ用の操作説明。タッチ対応PCでマウスに持ち替えた時はマウス用の案内に戻る。

### 緊急増援「ブロック・ラッシュ（仮称）」（Ver.0.1.3 で追加）
目的：大量分裂や貫通でブロックが激減しても、壊す対象が無くなる時間を短くする。
- 定期的な列補充はそのまま維持（増援とは独立して動く）。
- 発動条件：ブロック残数が基準量の 25% 以下（`RUSH_THRESHOLD_RATIO`）。基準量は 初期列数×列のマス数 = 84（`RUSH_BASELINE_BLOCKS` が 0 の時）。つまり **21 個以下で発動**。
  - 0 個より多い時は **3 列**（`RUSH_ROWS_LOW`）、**0 個の時は 5 列**（`RUSH_ROWS_EMPTY`）。
- 演出：「INCOMING!」と「+N ROWS」を表示し、警告音・画面の赤いフラッシュ・HUD下の点滅ラインを出す。`RUSH_NOTICE_TIME`（0.35秒）後から、1列ずつ `RUSH_ROW_INTERVAL`（0.15秒）間隔で、HUDの裏から定位置へ `RUSH_DROP_TIME`（0.2秒）かけて降りてくる。着地時に小さな音と粒子。
- 置き場所：
  1. 盤面の中で **丸ごと空いている段** を優先し、一番下のブロックの上から順に積み上げる（既存ブロックは動かさない）。
  2. 盤面が空の時は、届く列数ぶんの高さに上から積む（0個なら 0〜4段目）。
  3. 空き段が無い時だけ1段押し下げて最上段に置く。
- 危険ライン対策：侵入ラインまで `RUSH_SAFE_ROWS`（3列）以上の余裕がある段にしか置かない。押し下げる場合も、押し下げ後に3列以上の余裕が残る時だけ。置き場所が無い時は増援を出さない（通知も出さない）。
- 増援中もボールの移動・衝突判定は止めない。落下中の列にはまだ当たり判定が無く、着地した時点でブロックになる。
- 連続発動・無限ループ対策：
  - 1回の増援で補充するのは最大 `RUSH_MAX_ROWS`（10列）。
  - 全列が着地した時点でまだ閾値以下なら、同じ増援の中で追加補充する（上限の範囲内）。
  - 増援が終わったら `RUSH_COOLDOWN`（1秒）は次の増援を出さない。
- 増援の列は、定期補充の間隔短縮（`ROW_INTERVAL_DECAY`）には数えない（難易度を変えないため）。
- 落下中に定期補充で盤面が押し下げられた場合、着地点も一緒に1段ずらす。

### マウス操作（Ver.0.1.2 で追加）
- 操作モードは2種類。設定パネル（右下の⚙ボタン／O キー）で切り替え、localStorage に保存。
  - **マウスロック（既定）**：Pointer Lock API。ゲーム画面のクリックでロック開始。ロック中はカーソル非表示で、`mousemove` の `movementX` でパドルを動かす。画面端でもマウスを動かし続けられる。
  - **カーソル追従**：従来方式。カーソル位置にパドルが追従。
- マウス感度（ロック時のみ）：0.3〜3.0、既定 1.0（`MOUSE_SENSITIVITY_*`）。1.0 で画面上のカーソルと同じ見かけの速さ。
- パドルの目標位置は常にパドルが画面内に収まる範囲に制限（端で動かし続けても値を溜め込まないので、逆方向へすぐ動く）。
- Esc でロック解除。**ロックが解除されたら一時停止**。再開はゲーム画面のクリック（再ロックと同時に再開）。
- ロック待ちの状態では、マウスの絶対位置は無視する（ロック解除後にパドルが飛ばない）。
- ロック開始のクリックではボールを発射しない（発射は次のクリック）。ゲームオーバー画面では、ロック開始と同時にリスタートする（発射ではないため）。
- Space（分裂）・P（一時停止）・R（リスタート）・M（BGM）は従来どおり。ロック待ちの間は P / Esc で再開しない（パドルを操作できないまま再開するのを防ぐ）。
- ゲーム開始画面と一時停止画面に、操作モードと操作方法を表示。
- タッチ操作はモードに関係なく位置追従。

### 処理負荷
- requestAnimationFrame + 経過時間ベース移動。ボール同士の衝突なし。
- ブロックはグリッド配列で管理し、ボール周辺のマスだけ判定（ボール数に対して線形）。
- サブステップ移動（1ステップ最大 `SUBSTEP_MAX_DIST` px）で高速時のすり抜けを防止。
- 多数のボールは1パスでまとめて描画。`BALL_RECT_RENDER_THRESHOLD` 以上は四角形描画。
- デバッグ表示：FPS、ボール数、ブロック数、更新/描画時間。

## 3. 実装時に決めたこと（依頼に明記がなかった点）
- **吸収ブロックはボールを1個吸うと消える**（`ABSORB_CAPACITY`=1）。残り続けると永久にボールを吸い込むため。
- **アイテムは通常ブロックにだけ入る**（確率 `ITEM_BLOCK_CHANCE`=7%）。増殖・捕獲・吸収ブロックには入らない。アイテム付きブロックは中央に黒いカプセルと色付き文字（S 黄 / R 水色 / P 橙）で表示。
- 侵入ラインを越えて消えたアイテム付きブロックのアイテムは取得できない。
- アイテムの種類比率は 分裂40 : 回転20 : 貫通20 : グラビティ20（`ITEM_WEIGHT_*`。Ver.0.1.4 で G 追加に合わせて 50:25:25 から変更）。Ver.0.1.6 からはボール数に応じて P・G の重みを下げる（「難易度・得点バランス」参照）。
- **貫通中でも吸収ブロックに当たったボールは消える**（仕様7の「吸収ブロックに命中すると消滅」を優先）。
- 増殖ブロックの新ボールは反射後の向きから ±35° ずらした方向へ（`SPLIT_BLOCK_SPAWN_DEG`）。
- 捕獲ブロックから解放されるボールはランダムな方向。
- 分裂ボールは元の進行方向を中心に 150° の扇状に均等配置（`SPLIT_SPREAD_DEG`、360 にすると全方位）。
- 通常パドルの反射は当たった位置で角度が決まる従来方式（最大 62°）。回転パドルのみ物理反射。
- 回転パドルで加速したボールは最大 1.8 倍まで、その後基準速度へ徐々に戻る。
- 水平に近すぎる角度（14°未満）は補正して無限往復を防止。
- スコアは減点で 0 未満にならない。
- 補充間隔は列を追加するたびに短くなる（7秒→最短3秒）。
- ~~ブロックが少なくなると列補充が3倍速になる~~ → Ver.0.1.3 で廃止し、緊急増援に置き換えた（同じ目的の仕組みが重なり、両方が同時に動くと押し下げが急になって危険なため）。
- 侵入圧力は時間で自然減少する。
- タブが非表示になると自動で一時停止。
- ロック開始に失敗しても1回ではモードを変えない（Chrome は Esc 解除直後約1秒の再ロックを拒否するため）。3回連続で失敗したら、そのセッション中だけカーソル追従に切り替える（設定は保存しない）。
- 1イベントで 300px を超える `movementX` は異常値として無視（`MOVEMENT_SPIKE_LIMIT`）。ロック直後の最初の移動量も捨てる。
- 設定パネルを開くとロック解除＋一時停止。閉じた後はクリックで再開。
- ベストスコアを localStorage に保存。
- BGM「Neutral Vectors」（ユーザー本人の楽曲）を採用。最初の発射で再生開始、M で切替。
- （Ver.0.1.6）装甲ブロックにはアイテムを入れない。侵入ラインを越えた時の減点は特殊ブロック扱い（40点）。
- （Ver.0.1.6）時間倍率を掛けるのは通常・装甲ブロックだけ。増殖・捕獲ブロック（30点）とアイテム取得（50点）には掛けない（依頼の対象が通常・装甲のため）。
- （Ver.0.1.6）出現率・P/G 倍率の境目は「その値以上」で判定（例：ボール10個は 10〜29 の帯）。
- （Ver.0.1.6）開発用の B / Shift+B（ボール100 / 1000個追加）は負荷測定用なので上限119を無視する。
- （Ver.0.1.6）装甲が多い時は列の中のアイテムブロックの数が相対的に減る（アイテムは通常ブロックの7%のまま、通常ブロック自体が装甲に置き換わるため。ボール80個以上で約3割減）。
