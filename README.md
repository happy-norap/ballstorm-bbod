# BALLSTORM -BBOD-（エンドレス・ブロック崩し）Ver.1.1

ブラウザで動くエンドレス型ブロック崩し。上から次々と補充されるブロックを、増殖・分裂させた大量のボールで一気に壊す爽快感を楽しむゲームです。公開版 Ver.1.1。

### Ver.1.1 の追加内容
- スコア到達イベント：200万点「DOUBLE MILLIONAIRE!」、500万点「MEGA MILLIONAIRE!」、1,000万点「OVERDRIVE LEGEND!」（花火と称号の演出のみ。100万点の MILLIONAIRE は従来どおり +32球）
- ストック超過ボーナス：分裂ストックが3個の時に S を取ると「STOCK MAX! +5,000」

## 起動方法

- **いちばん簡単**：`index.html` をダブルクリックしてブラウザで開く（外部ライブラリなし・ビルド不要）
- **ローカルサーバーで開く**（開発時推奨）：
  ```
  powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8765
  ```
  その後 http://localhost:8765/ を開く
- **GitHub Pages**：このフォルダをそのままリポジトリのルートに置き、Pages を有効にするだけで公開可能（すべて相対パス）

## 操作

| 操作 | 内容 |
|---|---|
| マウス左右 | パドル移動 |
| クリック | マウスロック開始（ロックモード時の最初の1回） / ボール発射 / リスタート / 再開 |
| Space | 分裂アイテム発動（ストックを全消費。ボール10個以下の時だけ） |
| P | 一時停止 |
| Esc | マウスロック解除（＝一時停止）。カーソル追従モードでは一時停止 |
| R | リスタート |
| M | BGM オン/オフ |
| O / 右下の⚙ | 設定（操作モード：マウスロック / カーソル追従、マウス感度） |

既定は「マウスロック」モードです。ゲーム画面をクリックするとカーソルが消え、画面の外までマウスを動かしてもパドル操作が途切れません。

### スマートフォン（縦持ち推奨）
ゲーム画面の下に操作ボタンが出ます（PCでは表示されません）。

| 操作 | 内容 |
|---|---|
| 画面を左右になぞる | パドル移動（下のボタン列の空いている所をなぞってもOK。指を離すとその位置に留まる） |
| 画面をタップ | ボール発射 / 一時停止中は再開 / ゲームオーバー後はリスタート |
| SPLIT ×N ボタン | 分裂（Space と同じ。ストック0やボール11個以上の時は暗くなり使えない） |
| II / ▶ ボタン | 一時停止 / 再開 |
| ♪ ボタン | BGM オン/オフ |

### アイテム
アイテムはブロックの一部（S/R/P/G の印付き）に入っていて、壊した瞬間に自動で取得されます。

| 印 | アイテム | 効果 |
|---|---|---|
| S | 分裂 | ストック（最大3）。Space で全ボールが 4/8/12 倍。ストック3個の時に取ると +5,000点 |
| R | 回転パドル | 15秒間、3枚の補助パドルが回転 |
| P | 貫通ボール | 8秒間、ブロックを貫通して連続破壊 |
| G | グラビティ・リバウンド | 15秒間、パドル周りの力場でボールを引き寄せ、直前で強く弾き返す |

### 開発用キー（公開版では無効）
公開版（Ver.1.0 以降）では `js/config.js` の `DEV_KEYS_ENABLED` が `false` になっており、以下のキーはすべて無効です（デバッグ表示も出ません）。開発時に使う場合だけ `true` に戻してください。

| キー | 内容 |
|---|---|
| D | デバッグ表示（FPS・ボール数・ブロック数・処理時間）の切り替え |
| 1 / 2 / 3 / 4 | 分裂アイテム / 回転パドル / 貫通ボール / グラビティ・リバウンド を即時取得 |
| B / Shift+B | ボールを 100 / 1000 個追加（負荷測定用。ボール上限119を無視） |
| Ctrl+Shift+F8 | スコアを 999,900 点にする（ブロックを壊すと 100 万点イベントが発動） |
| Ctrl+Shift+F9 | 100 万点イベント「MILLIONAIRE」を直接発動（1プレイ1回） |

### 得点とボール数
- ボールは最大119個。分裂（Space）はボールが10個以下の時だけ使えます。
- 灰色の **装甲ブロック** は5回当てると壊れ、1,000点。ボールが多いほど多く出ます。
- 60秒ごとに得点倍率が ×1.1 ずつ上がります（最大10倍、SCORE の横に表示）。
- 100万・200万・500万・1,000万点に初めて届くと、それぞれ祝福の演出が出ます（1プレイ1回ずつ）。

## ファイル構成

```
index.html          起動ファイル
css/style.css       画面レイアウト
js/config.js        調整用定数（速度・出現率・持続時間など。調整はここ）
js/game.js          ゲーム状態・物理・衝突判定・ルール
js/render.js        Canvas 描画（HUD・デバッグ表示含む）
js/audio.js         効果音（WebAudio合成）と BGM
js/input.js         入力処理（マウスロック / カーソル追従 / キー操作 / 設定パネル）
js/main.js          起動・メインループ
assets/bgm/         BGM（bgm_main.mp3 = "Neutral Vectors"、作者本人の楽曲）
assets/images/      ogp.png（SNS共有用画像 1200×630。元画像はルートの「ネオンアーケード「ボールストーム」.png」）
tools/serve.ps1     開発用の簡易HTTPサーバー
docs/SPEC.md        仕様・決定事項・未決定事項
docs/WORKLOG.md     作業履歴
docs/HANDOFF.md     現在の状況と引き継ぎ
CLAUDE.md / AGENTS.md  AI向け作業ルール
```

スクリプトは ES Modules ではなく通常の `<script>` で読み込んでいます（`file://` で直接開いても動かすため）。
